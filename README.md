# Linear Room

**L'acoustique de ta pièce, mesurée et corrigée.** Un logiciel d'[ARTASYA](https://artasya-studio.com/linear-room.html).

Dessine ta pièce, place tes enceintes, mesure-la avec ton iPhone ou un micro de mesure : Linear Room te dit quoi construire, en quelle matière et où le poser.

## Télécharger

Les installateurs sont dans [**Releases**](../../releases/latest) :

| Système | Fichier |
|---|---|
| macOS 11 ou plus récent · puces Apple (M1, M2, M3, M4…) | `Linear-Room-…-mac-arm64.dmg` |
| macOS 11 ou plus récent · processeur Intel | `Linear-Room-…-mac-x64.dmg` |
| Windows 10 et 11 (64 bits) | `Linear-Room-…-win-x64.exe` |
| Linux (64 bits) | `Linear-Room-…-linux-x86_64.AppImage` |

L'app iPhone (le micro sans fil du logiciel) arrive bientôt sur l'App Store.

- **macOS** : ouvre le fichier `.dmg` et glisse Linear Room dans le dossier Applications. Le logiciel est signé et validé par Apple.
- **Windows** : au premier lancement, Windows peut afficher « Windows a protégé votre ordinateur ». Clique sur « Informations complémentaires », puis « Exécuter quand même ».
- **Linux** : rends le fichier exécutable (clic droit → Propriétés → « Autoriser l'exécution »), puis double-clique dessus.

## Gratuit et Pro

Le téléchargement donne la **version gratuite** : le schéma théorique de ta pièce et sa courbe de réponse mesurée avec ton iPhone.

Le reste (traitement proposé, scan sonore, réverbération, waterfall, micro de mesure, égaliseur, multicanal et Atmos) s'ouvre avec une **licence Pro**, personnelle, qui s'active sur un seul ordinateur (une fois, dans le logiciel). Elle s'achète sur [la page de Linear Room](https://artasya-studio.com/linear-room.html#versions).
